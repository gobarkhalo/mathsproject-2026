What does this project do?

You type three sets: U, A and B. The website draws them as a Venn diagram. When you tap an operation, the answer part turns yellow and the answer is written below. It also checks the laws on your own sets.

What is a set?

A set is a well-defined collection of objects. "Well-defined" means we can say clearly whether something is in it or not. Example: A = {2, 4, 6}. We write 4 ∈ A, and 5 ∉ A.

What is the universal set U?

The big set that contains all the elements we are talking about. A and B are always subsets of U. In the diagram it is the big rectangle.

What is a subset?

A ⊆ B means every element of A is also in B. Example: {2, 4} ⊆ {1, 2, 3, 4}. Use the "B inside A" preset to see it.

Union and intersection: what is the difference?

Union A ∪ B: elements in A or B or both. Intersection A ∩ B: only elements in both. Example: A = {1, 2, 3}, B = {3, 4}. Then A ∪ B = {1, 2, 3, 4} and A ∩ B = {3}.

What are difference and complement?

A − B: elements of A that are not in B. Complement A′: elements of U that are not in A, so A′ = U − A. Example with U = {1, 2, 3, 4, 5}, A = {1, 2, 3}: A′ = {4, 5}.

State De Morgan's laws with an example.

(A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′. Example: U = {1, 2, 3, 4, 5}, A = {1, 2, 3}, B = {3, 4}. A ∪ B = {1, 2, 3, 4}, so (A ∪ B)′ = {5}. Also A′ = {4, 5} and B′ = {1, 2, 5}, so A′ ∩ B′ = {5}. Both sides are equal. In words: "not (A or B)" is the same as "not A and not B".

What is a power set?

P(A) is the set of all subsets of A, including ∅ and A itself. Example: A = {1, 2} gives P(A) = {∅, {1}, {2}, {1, 2}}. That is 4 subsets, and 2² = 4. If A has n elements, P(A) has 2ⁿ.

When are two sets disjoint?

When they have nothing in common, so A ∩ B = ∅. Example: the set of even numbers and the set of odd numbers. Use the "Disjoint" preset.

Give a real-life example of sets.

In a class, A = students who play cricket and B = students who play football. A ∩ B are students who play both. A ∪ B are students who play at least one of the two games.
