Top Viva Tips for Chapter 1:
  • Cardinal Number Formula: $n(A \cup B) = n(A) + n(B) - n(A \cap B)$.
  • De Morgan's First Law: $(A \cup B)' = A' \cap B'$.
  • Power Set Cardinality: If a set has $n$ elements, its power set has $2^n$ subsets.
